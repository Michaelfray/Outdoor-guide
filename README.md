# Friluftsguiden (Outdoor Guide)

A website for finding trails for hiking, paddling, cycling and skiing in Stockholm County. Visitors can browse trails by activity or by municipality, check the weather, rate trails and sign up for a newsletter. Everything is available in Swedish and English.

Built by a group of three in the course *CMS Development* at Nackademin (CMS25), autumn 2026.

## What you can do on the site

- **Find a trail:** browse by activity (hiking, paddling, cycling, winter) through the mega menu, or by region and municipality.
- **Filter and search:** filter trails on the start page and search for trails or municipalities.
- **Weather:** a three-day forecast for Stockholm on the start page and for each trail (Open-Meteo).
- **Ratings:** logged-in members can rate trails. The average is shown on the trail cards.
- **Map:** each trail page shows a map, loaded only if the visitor accepts all cookies.
- **Members:** register, log in and see your account page.
- **Newsletter:** sign up, get an email when a newsletter is published, and unsubscribe with one click.
- **Two languages:** Swedish (`/`) and English (`/en`).

## How the group shares document types

Each person has their own local database, so changes made in the Umbraco backoffice are not shared through Git. Instead, everything the others need (document types, templates, languages, important pages and content) is written as steps in an **Umbraco migration plan**, `Business/Migrations/SiteMigrationPlan.cs`. The steps run automatically once per database when the site starts. Each step first checks whether the thing already exists, so nothing anyone has changed in the backoffice is overwritten.

## Run it locally

1. Install the [.NET 10 SDK](https://dotnet.microsoft.com/download).
2. Clone the repo and run:
   ```
   dotnet run
   ```
3. Open `https://localhost:44348`, go through the Umbraco installer and choose SQLite.
4. Stop the site and start it again. The migration plan then creates the document types, languages and content.

To test emails locally, install and start [smtp4dev](https://github.com/rnwood/smtp4dev) (`dotnet tool install -g Rnwood.Smtp4dev`, then `smtp4dev`). The emails show up at `http://localhost:5000`.

## Folder overview

| Folder | Contents |
|---|---|
| `Business/Migrations` | The migration plan and its steps |
| `Business/Services` | Weather, ratings, search, newsletter and more |

## Accessibility

We aimed for WCAG 2.1 AA: keyboard navigation everywhere, visible focus, enough colour contrast and screen reader text where needed. Lighthouse gives 94–97 for performance and 100 for accessibility, best practices and SEO.
